BUG FIX: IPO SERVICE COLUMN MISMATCH
=================================================================

Issue Discovered:
When testing the v2 allotment API, initial requests returned:
```json
HTTP/1.1 500 Internal Server Error
{"success":false,"error":{"code":"INTERNAL_ERROR","message":"Failed to fetch IPO details"}}
```

Root Cause Analysis:
The IPOService.GetIPOByID() query was selecting `registrar_id` column:
```go
query := `SELECT i.id, i.name, ..., i.registrar, i.registrar_id, i.stock_id, ...`
```

However, the actual ipo_list table schema has `registrar_company_code` instead:
```
$ docker exec ipo-backend-db-1 psql -U postgres -d ipo_db -c \
  "SELECT column_name FROM information_schema.columns WHERE table_name = 'ipo_list' AND column_name LIKE '%registrar%';"

      column_name       
------------------------
 registrar
 registrar_company_code
```

Fix Applied:
File: services/ipo_service.go (lines 879-885)
Changed: `i.registrar_id` → `i.registrar_company_code`

```go
query := `SELECT i.id, i.name, i.company_code, i.description, i.price_band_low, i.price_band_high, 
             i.issue_size, i.open_date, i.close_date, i.result_date, i.registrar, i.registrar_company_code, i.stock_id, 
             i.form_url, i.form_fields, i.form_headers, i.parser_config, i.status, i.subscription_status,

             FROM ipo_list i
```
